# 📚 Library Management System (LMS)

Welcome to the **Library Management System (LMS)** — a Django-based web application created to simplify the management of books, members, and borrowing records.  

This project was built as part of a collaborative learning experience by a passionate team of developers and learners.  

---

## 🌟 Project Overview

The **Library Management System** allows:
- 📖 Managing books and availability  
- 👥 Adding and tracking members  
- 🔐 User authentication (Sign up / Login / Logout)  
- 🕮 Borrowing and returning of books  
- 🧑‍💼 Admin privileges for book & member control  

Built with a **simple interface**, it ensures an easy workflow for both librarians and users.

---

## 🛠️ Tech Stack

| Layer           | Technology     |
|-----------------|----------------|
| **Framework**   | Django (Python)|
| **Frontend**    | HTML5, CSS3    |
| **Database**    | SQLite3        |
| **Version Control** | Git & GitHub   |

---

## 🧩 Key Features

- User-friendly interface for members and admins  
- Secure login and signup functionality  
- Separate privileges for normal users and admin users  
- Borrow and return functionality with book tracking  
- Organized, clean, and responsive UI
